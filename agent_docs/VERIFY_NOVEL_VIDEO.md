# 小说与视频板块验证指引

应用启动后(桌面 `npm run desktop:dev`,或安装 nightly APK),按以下步骤走一遍即为完整验收。

## 视频(fs1 列表 + missav 优先播放)

1. 首页 → 顶部分段选 **「视频」**
2. 列表卡片:应有完整标题(非纯番号);带橙色「中字」角标的为字幕版
   (同番号普通版/字幕版已去重,只显示一张)
3. 搜索框输入番号(如 `ssis`)→ 结果正常翻页
4. 点任意卡片:
   - 首次会闪现"视频源连接"小窗(missav 网关)后自动隐藏
   - 详情页标题下方应有蓝色「**missav 优先线路**」徽标(备用为 fs1 线路)
   - 有字幕版时显示橙色「中文字幕」徽标且播放走字幕版
   - 播放器应正常出画、可拖动进度

## 小说(hlib.cc)

1. 首页 → 分段选 **「小说」** → 打开书架
2. 点右上 **「登录 / 浏览 hlib」** → 弹出网关窗口:
   - 登录 `czn@bf.cc` / `AKi%w7gpjzQVlE`
   - 如出现 Cloudflare 验证框,点一下
   - 网关是个内嵌浏览器,可正常浏览站内内容;点 X 只是隐藏,登录状态保留
3. 回到书架:
   - 搜索框输入书名/作者 → 「搜索」(首次会自动探测端点,稍慢)
   - 或点「最新」拉首页最新系列
   - 结果条目点「+ 书架」入库(无需贴链接)
   - 也可在网关里复制系列链接(`/s/xxx`)粘贴添加
4. 点书架条目进阅读器:
   - 右上「目录」展开章节列表,点选跳章
   - 底部上一页/下一页;页到头自动进下一章
   - 退出后再进,自动续读到上次位置

## 已知边界

- missav 网关不可用时视频自动回退 fs1 线路,仍可观看
- hlib 验证/登录过期时,任何小说操作会自动弹回网关窗口,重新点一次验证即可
- 站点对连续抓取敏感:系列目录分页拉取已内置 4 秒间隔

## 问题反馈格式

哪一步、什么现象(报错文字/黑屏/徽标缺失),贴给维护者即修。
